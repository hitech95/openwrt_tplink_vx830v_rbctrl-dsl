# rbctl-voip

Two-port SIP service for the VX830v, shipped alongside [rbctl-dsl](../rbctl-dsl/README.md) in the [OpenWrt feed](../README.md). Baresip 4.9.0 handles SIP and media; its `rbctl_voip` module talks to the **stock EcoNet voice board** over raw Ethernet on the management VLAN. OpenWrt manages the service with procd, UCI and ubus; LuCI is optional.

**Status:** hardware tests cover both analog ports, simultaneous calls, two-way speech, R-button hold/resume and SIP registration after reboot. The full host module suite passed 33/33. M5 and M5.1 await only the deferred clean-image install test. See [features vs OEM](../../docs/voip/feature-status.md) and [test results](../../docs/voip/test-report.md#m5-review-verification).

| Crate | Kind | What it is |
|---|---|---|
| `rbctl_voip_proto` | rlib | Protocol core, sans-I/O: envelope + CRC-16/ARC, 132-byte DSP records, the DD01/DD02/DD03 link state machine. No `unsafe`, no allocation, cannot panic on any input. |
| `rbctl_voip_net` | rlib | Linux transport: one `AF_PACKET` socket per EtherType on `lan0.500`, via the shared `af_packet` crate. |
| `rbctl_voip_ffi` | staticlib | C ABI for the baresip module. Header: `crates/rbctl_voip_ffi/include/rbctl_voip.h` (generated by cbindgen, committed). |
| `rbctl_voicectl` | bin `rbctl-voicectl` | Bring-up/diagnostic CLI for the M2 hardware tests. |

## Wire in one table

| EtherType | Who starts | Subtypes | Purpose |
|---|---|---|---|
| `0xDD01` | master | `1a` init, `1b` attach, `16` DSP record | request + 4-byte BE status reply from the board |
| `0xDD02` | board | `18` | DSP event (hook, digits, results) + master's 4-byte status reply |
| `0xDD03` | either | `19` | RTP/RTCP datagram with `be16 slot, be16 selector` prefix |

See the [master-side protocol](../../docs/voip/board-link.md), [EcoNet peer](../../docs/voip/peer.md) and [library design](../../docs/voip/foss-design.md).

## Build and test

```sh
cargo build --workspace
scripts/check.sh            # Rust, ABI and available optional checks
BARESIP_PREFIX=/path/to/host-4.9 scripts/check.sh  # include the full module suite
cargo test --workspace --features rbctl_voicectl/fixture
```

What the tests cover:

* `rbctl_voip_proto/tests/golden.rs` — 163 golden vectors produced by the
  original C prototype (`tests/vectors/gen_c.c`); byte-for-byte parity.
* `rbctl_voip_proto/tests/props.rs` — property tests (round-trips, decoders
  are total).
* `rbctl_voicectl/tests/cli.rs` — the real binary through 17 scenarios
  against the Python board emulator (`tests/peer-emu/`), over a Unix
  datagram pair (`fixture` feature, never in release packages).
* `rbctl_voip_ffi/tests/c_smoke.rs` — `tests/ffi/smoke.c` built against the
  generated header and staticlib with ASan/UBSan; header freshness.
* `tests/qemu/diff.py` — compares our encoders with the original OEM AArch64
  routines under `qemu-aarch64` (needs the extracted OEM rootfs; skipped
  otherwise).

Fuzzing (nightly): `cd crates/rbctl_voip_proto && cargo +nightly fuzz run
frame_valid -- -max_total_time=600` (targets: `frame`, `frame_valid`,
`record`, `link`).

Regenerate the C header after changing `rbctl_voip_ffi`:

```sh
cd crates/rbctl_voip_ffi && cbindgen --config cbindgen.toml --output include/rbctl_voip.h
```

## Using rbctl-voicectl on the router

Needs root or `CAP_NET_RAW`, and the VLAN device (default `lan0.500`). Use these bring-up commands only when the managed voice service is stopped and no calls are active.

```sh
rbctl-voicectl init --locale 10          # cold or warm initialization
rbctl-voicectl events                    # hook/flash/digit events
rbctl-voicectl keypad                    # verify 1234567890*# on both lines
rbctl-voicectl ring --line 1 --cid Test,5550100
rbctl-voicectl tone --line 0             # dial tone 6 s, then stop
rbctl-voicectl loop --line 0 --to 1      # PHONE1 <-> PHONE2 audio
```

`RUST_LOG=debug` adds logs on stderr. Stdout is a protocol transcript that
never contains dialled digits, caller identity or audio.

## Tone characterization (M4)

For M4 tone characterization, initialize the idle board at the desired locale,
then use `rbctl-voicectl tone --line 1 --sel 1 --duration-ms 5000`. Selector 0
only stops; 31 invokes the peer's type-II CID path. The full selector lookup
and acoustic results are in `docs/voip/peer.md`. With the mic on the earpiece,
`python3 -B tests/live/tone_probe.py ROUTER REMOTE_CLI PIPEWIRE_MIC --line 1 4 1 2 3`
prints estimated peaks and on/off intervals, without saving raw audio. Stop any
other board owner first. Confirm tone names separately with the receiver at the ear.

## OpenWrt

Select `rbctl-voip` for the full service, or `luci-app-rbctl-voip` to install both the service and its web interface. The default configuration enables no SIP accounts. Provision one in **LuCI → Services → Telephony** or `/etc/config/voip`; check board, account and line state with `ubus call voip status`. See the [package profiles](../README.md) and [deployment and troubleshooting guide](../../docs/voip/m5-integration.md).
